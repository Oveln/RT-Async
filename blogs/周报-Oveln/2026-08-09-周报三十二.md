# 第三十二周：跨核共享内存驱动抽象（ov-shm）+ K3 IPC 联调推进

## 一、本周完成事项

### 1. ov-shm：设备树驱动的跨核共享内存 + notifier 抽象（QEMU 跑通）

共享内存地址来源从 `amp.toml` 编译期常量改为 **DT 驱动 probe**：

- 新增 `modules/ov-shm`：`ShmDriver`（compatible `ov,rt-async-amp`，probe 读 `reg` 得基址）+ `PeerNotifier` trait（`ClintMsipNotifier` 后端，`fence(Release)` + 写 MSIP 通知对端）；
- `intercom` 重构：基址改 `AtomicUsize`，**先初始化共享内存再发布基址**（防 ISR 读到未初始化 ring buffer）；
- `its/rt-async-shm.dtsi`：共享内存节点单一真相源，AP/rt-async 两侧 DTS 宏参数化引用同一节点；
- `xtask`：`compile_dtb` 升级为 `cc -E → dtc` 编译链 + 依赖追踪。

**验证**：QEMU 端到端 `user-test-rpc`/`user-test-sched` 全通过。

### 2. K3 IPC 双核通信联调

- **K3 DTS**：新增 `rt-async@c0800000` 共享内存节点（SRAM 68KB，与 AP 侧对齐）；
- **mailbox.rs**：`MboxK3` 实现 `PeerNotifier`（`signal(0)` 触发 AP 中断），MBX4 probe 后注册进 NOTIFIER slot；
- **`ipc_demo`**：K3 RT24 侧 IPC demo——弹性忙等处理 + MBX4 `recv().await` 中断唤醒（IRQ 69）；`intercom.rs` 移植到 ov-shm 基址 + mailbox 通知；
- **`user-test-mbox`**：AP 侧自测——ioctl 软件注入 new_msg 验证 mailbox→APLIC→IMSIC→CPU→handler 全链路；
- **构建链**：k3-flash.sh 支持 `K3_TARGET` 刷任意 rcpu1 bin；xtask 新增构建目标；StarryOS 构建重构为 tg-xtask（`--smp 1` 强制单核）。
